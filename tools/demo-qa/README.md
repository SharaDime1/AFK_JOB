# Демоверсия AziFit

- `azifit-demo/index.html` — версия для первого показа, открывается напрямую и через HTTP. Для передачи заказчику используйте всю папку azifit-demo.
- `azifit-full/` — независимая точная копия полной версии public на момент подготовки демо, со всеми разделами и данными.
- `public/` и `cloudflare-pages/` — прежние версии, без изменений.

В демо оставлены первый экран, женское и детское направления, 11 услуг и контакты. Сохранены исходные CSS, SVG, палитра, адаптивность, reveal-анимации, параллакс и мобильное меню. Добавлена пометка «Предварительная версия». Ссылки услуг ведут к контактам, кнопки записи открывают WhatsApp напрямую.

Подробный прайс, расписание, команда, отдельные LPG/Интенсив-блоки с подробностями, FAQ с ценами, форма заявки, суммы, фильтры и копирование сообщений не входят в демо. Полные data.js и app.js в демо не подключены и не копируются. Они остаются в обеих полных версиях.

Для восстановления всех разделов используйте public/ или azifit-full/ целиком; не смешивайте полный app.js с сокращённой HTML-страницей. Изменения дизайна демо не переносятся в полный вариант автоматически.

Демонстрация имеет noindex/nofollow и robots.txt Disallow, чтобы не конкурировать с будущим основным сайтом. Это не ограничение доступа. Публикация не выполнялась.
